# admit

> This text was generated by an LLM ([how cgwalters uses LLMs](https://github.com/cgwalters/cgwalters#llms)). cgwalters has not reviewed it yet.

Fails the job unless `github.repository_owner_id`, the calling
repository's owner, is one of the numeric ids in
[owners.json](owners.json). The logins there are for the reader; only the
ids are compared, since a login can be renamed and registered again by
someone else.

Any public repository can call this repository's reusable workflows, and
the identity tokens minted in such a run carry their `job_workflow_ref`.
The dispatch wrapper lets the caller pick the agent job's runner, and the
review wrapper takes it from the caller's variables; on a self-hosted
runner its owner can mint identity tokens for any audience. Both wrappers
therefore run this action in a job on a hosted runner that the agent job
waits for, so a caller from outside these organizations is refused before
its runner is ever given the job.

```yaml
- uses: cgwalters-forge/actions/admit@main
```

To admit another organization, add its login and id
(`gh api users/LOGIN --jq .id`) to owners.json; the inference broker and
the tailnet federation must admit the same ids.
