# deployment

> This text was generated by an LLM ([how cgwalters uses LLMs](https://github.com/cgwalters/cgwalters#llms)). cgwalters has not reviewed it yet.

Outputs this deployment's defaults from [deployment.json](deployment.json),
so that another deployment's copy of this repository changes the file, not
the wrappers' defaults. The dispatch wrapper uses them only where neither
its input nor the calling repository's variable sets the value; the review
wrapper, which has no inputs, reads `agent-model` from its admit job where
the variable is unset. The copy must still repoint the wrappers'
`uses: cgwalters-forge/actions/...` lines at itself, which GitHub requires
be literal: until it does, it reads this repository's file.

| Key | Output | Wrapper input, else variable |
| --- | --- | --- |
| `agent-config-repo` | the agent configuration repository (opencode's and claude's), `OWNER/NAME` | `agent-config-repo`, else `AGENT_CONFIG_REPO` |
| `agent-model` | the agent's model, as the inference proxy serves it (`PROVIDER/MODEL` or a bare name) | `model`, else `AGENT_MODEL` |

Every key is required and no other is accepted, so a misspelt key fails
the run instead of leaving the setting at this deployment's value.

```yaml
- uses: cgwalters-forge/actions/deployment@main
  id: deployment
```
